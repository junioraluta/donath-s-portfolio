DESIGN SYSTEM & VISUAL LANGUAGE
1. Design Direction
Design Concept
Executive Minimalism
The website should combine:
    • Corporate credibility 
    • Consulting-style presentation 
    • Modern web aesthetics 
    • Strong typography 
    • Clean spacing 
The visual inspiration is closer to:
    • Consulting firms 
    • Executive profiles 
    • Premium SaaS websites 
Not:
    • Developer portfolios 
    • Startup landing pages 
    • Creative agency experiments 

2. Brand Identity
Brand Personality
The design communicates:
Attribute	Visual Expression
Trust	Dark navy tones
Professionalism	Clean layouts
Leadership	Strong typography
Stability	Balanced spacing
Intelligence	Data-focused sections
Premium quality	Gold accents

3. Color System
Primary Colors
Navy — Primary Brand Color
#0B1F3A
Usage:
    • Navbar 
    • Hero background 
    • Footer 
    • Important sections 
Meaning:
Authority, trust, professionalism.

Gold — Accent Color
#C9A227
Usage:
    • Highlights 
    • CTA details 
    • Achievement indicators 
    • Small decorative elements 
Meaning:
Achievement, excellence, premium quality.

White
#FFFFFF
Usage:
    • Main backgrounds 
    • Cards 
    • Text contrast 

Light Gray
#F5F7FA
Usage:
    • Alternate sections 
    • Background separation 

Dark Text
#111827
Usage:
    • Body text 
    • Headings 

Color Usage Rule
Avoid excessive gold.
Gold is a highlight, not the main color.
Example:
GOOD:
Navy background

White text

Gold button accent
BAD:
Gold background everywhere
The goal is luxury, not decoration.

4. Typography System
Primary Font

Usage:
    • Body 
    • Navigation

    • Descriptions

Modern.
Professional.

Heading Font

Usage:

Reason:
Adds executive/editorial feeling.

Example:

Driving Operational Excellence Through Strategy and Execution

15. Accessibility Requirements
Must include:
    • Proper heading hierarchy 
    • Alt text for images 
    • Keyboard navigation 
    • Good color contrast 
    • Focus states 
    • Semantic HTML 

16. Performance Rules
The website must prioritize speed.
Requirements:
    • Optimized images 
    • Lazy loading 
    • Minimal dependencies 
    • Compressed assets 
    • No unnecessary animations 
Target:
90+ Lighthouse score.
